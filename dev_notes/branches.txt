    owned window: panel's owner (GWLP_HWNDPARENT) = RCLIENT while docked → stays just above
      the client, not above other apps (always-on-top dropped), minimizes with it
    follows via SetWinEventHook(EVENT_OBJECT_LOCATIONCHANGE) on the client pid (out-of-context,
      installed on Tauri's main thread) → same-frame moves; 250 ms poll only for show/hide etc.
    visible bounds via DWMWA_EXTENDED_FRAME_BOUNDS: our undecorated window still has 7 px
      invisible borders (left/right/bottom), the client none; one SetWindowPos (move+size)
    owner dropped on the client window's HIDE/DESTROY event (Windows destroys owned windows
      with their owner) and when undocking; re-owned by the poll
    rejected: SetParent into the client (cross-process child window, shares CEF input queue)
    checked with a replay + live client window: rects match exactly, owner set
- macOS dock (todo, same shape: dock::follow per OS, docked_rect shared):
    find client: CGWindowListCopyWindowInfo, owner LeagueClientUx / "League of Legends",
      kCGWindowBounds + owner PID (bounds/PID need no Screen Recording permission, titles do)
    follow: AXObserver on the client's AXUIElement, kAXMovedNotification/kAXResizedNotification
      (needs the Accessibility permission, ask via AXIsProcessTrustedWithOptions); without it,
      poll CGWindowList ~60 Hz
    stacking: no cross-process owned/child windows (addChildWindow is same-process only); try
      orderWindow(.above, relativeTo: <client window number>) and re-order on
      NSWorkspace didActivateApplication; fallback: floating level only while the client is
      frontmost. Verify on a Mac
